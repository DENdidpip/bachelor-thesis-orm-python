# Bachelor's Thesis – Object-Relational Mapping in Python

This repository contains materials for my bachelor's thesis focused on object-relational mapping (ORM) in Python using SQLAlchemy.

The thesis includes a theoretical analysis of ORM concepts, a comparison of Java Persistence API (JPA) and SQLAlchemy, and a practical Python tutorial.

## Repository Structure

- `bakalarka_java/` – Java and JPA examples
- `bakalarka_py/` – Python and SQLAlchemy examples
- `analiticka_castl.docx` – Analytical part of the thesis
- `tutorial.docx` – Practical Python tutorial

## Technologies

- Java / JPA
- Python / SQLAlchemy
- PostgreSQL / SQLite
